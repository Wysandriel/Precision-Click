# Reaction Arena：Rift Edition

這個專案是對原始 **Precision Click / Reaction Arena** 小遊戲的改造版本，加入了多階段挑戰、Roguelite 式升級選擇與簡易養成系統。目標是讓玩家在每局遊戲中做出策略選擇，累積高分並取得長期動機。

## 遊戲玩法

- 點擊場上出現的 **綠色** 目標獲得分數。
- **金色** 目標得分較高，出現機率可透過升級提升。
- 點到 **紅色炸彈** 會失去生命，生命歸零則遊戲結束。
- 每一局包含四個階段，每階段時間與難度逐漸增加；最後一個階段視為 Boss 戰。
- 每完成一個階段都會出現三張隨機升級卡，選擇其一來強化你的能力。例如提高分數倍率、增加生命、增加金色出現率、延長階段時間、增大目標等。
- 遊戲結束後會顯示本局分數、獲得的金幣（分數÷10 取整）和簡要評語，並將摘要存入瀏覽器的 localStorage，方便回到主選單時查看上一次成績。

## 執行方式

1. 將本資料夾上傳到 GitHub 倉庫根目錄或任何靜態伺服器。
2. 透過 GitHub Pages 或其他網站托管服務，即可在瀏覽器中遊玩。
3. 開始遊戲後盡量保持連續命中並慎選升級，挑戰更高分數！

## 主要改進

- **多階段闖關**：遊戲不再只有一段計時，改為連續四個階段，每階段時間、目標大小與陷阱機率有所不同。
- **隨機升級**：完成階段後可從三張隨機升級中選擇一張，升級能影響分數倍率、生命、金色目標機率、目標尺寸、炸彈懲罰等，使每局產生不同的流派與策略。
- **長期養成**：遊戲結束後會將本局成績存入 localStorage，在主選單顯示上一局摘要，包括分數、金幣、完成階段數與剩餘生命，讓玩家有長期追求的目標。
